# Product Principles — Fiboprana (root mirror)

> Read at runtime by the synthesis/idea modules. Derived from the locked PRD
> (`../fiboprana-site/docs/PRD.md`, decisions of 2026-07-31) and the positioning doc.

1. **No scores, no grades, no verdicts.** Trends in plain language over weeks. The
   product must never make the user feel behind — anti-nocebo framing is a design
   constraint, not a tone choice.
2. **The check-in is the product.** ~30 seconds, minimal core + optional depth.
   Everything builds on the daily mind+body log.
3. **Device-optional, always.** Manual check-ins are a first-class path. Wearable sync
   and history import are enhancements — import is strictly optional and NEVER a gate.
4. **Show, don't interpret.** Surface patterns and correlations from the user's own
   data; the user decides what they mean. No black-box coach, no diagnosis, no
   prescriptions.
5. **Fast first proof.** The first sessions should surface a real mind↔body pattern
   from the user's own data — time-to-first-correlation is the churn cliff.
6. **Trust is a feature.** Transparent billing, one-click cancel, data exportable and
   never sold or fed to ad-tech. Built to survive FTC HBNR / WA MHMDA scrutiny.
7. **General wellness, firmly.** Never cure/treat/diagnose; never "measures your
   stress." Experience-framing only ("see whether it's working" = noticing, not
   efficacy).
8. **Practice depth over feature breadth.** Meditation / breath / qigong / prana
   taxonomy done credibly beats ten shallow integrations. Build thin, then deepen what
   real usage validates.
