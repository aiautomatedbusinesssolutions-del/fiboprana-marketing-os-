Which model runs each agent

Every agent resolves its model through one config layer: an env var wins, then whatever you set here, then the built-in default. Edits save to fleet/models.json and take effect on the agent's very next run, no restarts. With the OpenRouter key set, any OpenRouter slug is valid here.

One row per agent: how often it ran, how often it failed, what it cost, and which model did the work. This is how a model change on the panel above gets judged: swap the model, watch the success rate and cost here over the next runs.
